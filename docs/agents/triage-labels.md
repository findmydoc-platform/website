# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | The work is fully specified for an agent. |
| `ready-for-human` | `ready-for-human` | The work requires human implementation. |
| `wontfix` | `wontfix` | The work will not be pursued. |
